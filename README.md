# Music Bingo

A music bingo game for work nights: 4 rounds, a 3 × 5 card per round, and four wins per round
(any 5 songs → 1 line → 2 lines → full house). Each player gets one printed A4 sheet with a code;
the host types the code to check a claim.

## Run it
- **Mac:** double-click `music-bingo/Start Music Bingo.command` (first time: right-click → Open).
- **Windows:** double-click `music-bingo/Start Music Bingo (Windows).bat` (needs Python).
- Don't open `index.html` directly — YouTube won't play from a file.

## Use it
1. **Setup:** paste each round's songs (`Title - Artist | YouTube link`). Ready-made lists are in `song-lists.txt`.
2. **Print cards:** one sheet per player, all 4 rounds, one code.
3. **Play:** YouTube mode plays clips automatically; manual mode is for a jukebox.

Songs and progress are saved in the browser. Use *Save backup file* in Setup to move them to another laptop.
